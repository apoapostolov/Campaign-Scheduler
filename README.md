# Campaign-Scheduler

Scheduler and tracker for D&D (and other TTRPG) campaigns, sessions, player availability, and events.

Markdown-first for version control, easy editing, and integration with your existing notes, Foundry VTT, and automation stack.

## Goals
- Track campaign timelines, session logs, and recurring events
- Manage player availability and scheduling conflicts
- Generate calendars, reminders, and reports
- Stay lightweight and file-based (no heavy external services required)

## Proposed Structure
- `campaigns/` — one directory per campaign with notes, arcs, and schedules
- `players/` — availability calendars, contact info, preferences
- `events/` — upcoming sessions, one-shots, or special events
- `templates/` — reusable Markdown templates for logs, characters, etc.
- `integrations/` — scripts or notes for calendar sync, VTT hooks, Discord/Telegram alerts
